## Current workflow configuration and engine

- `configs/workflows/disassembly_A.yaml` is absent. `disassembly_A.draft.yaml` is `HUMAN_REVIEW_REQUIRED`, has candidate label states and no transitions. It is a review scaffold, not executable policy.
- Real activation is guarded by `workflow_is_enabled`: absent/false `enabled` disables execution; true requires `status: HUMAN_VALIDATED`. The validator also requires approval metadata and process-owner decisions.
- `WorkflowEngine` is a deterministic candidate-path evaluator. It accepts only events marked `evidence_status == "sufficient"` for state progression; non-sufficient observations are retained in `event_statuses` and a violation record, but not in `events` (the engine's applied-event history). This distinction is partly explicit and partly lossy for audit consumers.
- Current schema is `ActionEvent` with worker/action, start/end time and frame, duration, confidence, video ID, evidence status defaulting to `unknown`, view, event ID and evidence references. `from_dict` restores evidence references to a tuple.

## Metrics and temporal decoding

- `action_metrics` used a background class ID parameter defaulting to `0`, truncated unequal input arrays to `min(len(gt), len(pred))`, and rejected only the resulting empty sequence. Pipeline callers explicitly passed `background_id=0`; config declared the background symbol as `NULL` but did not resolve its class index at the call site.
- CP06 metric aggregation computes temporal measures per execution before aggregation; CP07 audit records the pooled definitions. This checkpoint will not recompute or overwrite those frozen values.
- `smooth_labels` applies a centered local majority with center-label then smallest-ID tie-break. `merge_short_segments` merges short runs toward a neighboring label, choosing the left neighbor for interior runs. `decode_segments` derives sample period from median timestamp differences and maps sampled segment extents to frame/time intervals.
- Existing tests cover representative smoothing/merge/window behavior, but not all decoder invariants (empty/misaligned input, monotonic timestamps, probability dimensions, or edge-case run merging). No decoder defect is yet confirmed; changes require a reproduced implementation bug.
